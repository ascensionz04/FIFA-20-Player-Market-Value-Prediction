# FIFA-20-Player-Market-Value-Prediction

## Overview

This project explores the EA FIFA 20 player dataset and applies multiple machine learning regression models to predict a football player's market value (value_eur) based on their attributes and performance statistics.

The notebook includes data preprocessing, exploratory data analysis (EDA), feature engineering, model training, hyperparameter tuning, and performance evaluation.

## Dataset

The project uses the FIFA 20 player dataset, which contains information such as:

Player demographics (age, nationality, club)
Technical attributes (shooting, passing, dribbling, etc.)
Overall rating and potential
Position information
Market value (value_eur)

Source: https://www.kaggle.com/datasets/stefanoleone992/fifa-20-complete-player-dataset?select=players_20.csv
